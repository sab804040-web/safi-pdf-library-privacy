Last Updated: November 18, 2026

SAFI PDF LIBRARY respects your privacy. This policy explains how information is handled when you use the application.

1. Information We Collect

Ordinary users do not need to create an account or sign in.

The application uses Firebase Authentication for administrator login. The authentication service processes the administrator's email address and account identifier.

When the administrator uploads a book, the application sends:

  • PDF book file
  • Book title
  • Author name
  • Book description
  • Firebase authentication token used to authorize the upload

2. How We Use Information

We use this information to:

  • Authenticate the administrator.
  • Manage the online book library.
  • Store and display book information.
  • Upload, view, and download PDF books.
  • Maintain application security and functionality.

3. Third-Party Services

Google Firebase

  • Firebase Authentication for administrator login.
  • Firebase Firestore for book information.

Cloudflare

  • Cloudflare Workers and storage services for administrator-uploaded PDF books.

These service providers may process technical information, such as IP addresses and connection data, to provide and secure their services.

4. Data Sharing

We do not sell personal information.

Information may be processed by service providers to operate the application. Books uploaded by the administrator may be made available to application users.

5. Data Security

The application uses HTTPS connections for its Firebase and PDF upload services to help protect information during transmission.

6. Data Retention and Deletion

Book information and uploaded PDF files may remain stored while they are available in the library.

For privacy questions or requests to remove information associated with the application, contact us using the email below.

7. Children's Privacy

SAFI PDF LIBRARY does not knowingly request personal information from children.

8. Changes to This Policy

This policy may be updated when application features or data practices change.
